# Kincony-KC868-A16
Базовая прошивка для Kincony KC868-A16 на базе ESP32.
<img width="699" height="567" alt="image" src="https://github.com/user-attachments/assets/7ce049a1-d4f4-4c7c-bb5e-d967c86fd524" />

Этот проект представляет собой готовую к использованию прошивку для контроллера **Kincony KC868-A16**. Устройство предназначено для промышленной и домашней автоматизации, мониторинга датчиков и управления исполнительными механизмами.

## 📋 Основные возможности
* **Два сетевых интерфейса:** Работа по кабелю Ethernet (LAN8720) и собственная точка доступа Wi-Fi (AP).
* **Веб-интерфейс:** Удобное управление устройством через браузер с любого устройства в сети.
* **Управление реле:** 16 каналов реле (через PCF8574).
* **Мониторинг входов:** 16 дискретных входов (через PCF8574).
* **Датчики (RS485/Modbus):** 
  * Датчик температуры и влажности (THS).
  * Датчик температуры PT100.
* **Авторизация:** Защита веб-интерфейса логином и паролем (Basic Auth).
* **Гибкая настройка:** 
  * Смена логина/пароля.
  * Настройка статического IP-адреса для Ethernet.
  * Изменение имени и пароля Wi-Fi точки доступа.
  * Смена цветовых тем интерфейса.
* **Энергонезависимая память:** Все настройки (сеть, пароли, темы) сохраняются в NVS (Preferences) и не сбрасываются при перезагрузке.

## 🛠️ Аппаратная конфигурация (по умолчанию)
Все пины и адреса устройств задаются в файле `config.h`. Вы можете изменить их под свою ревизию платы.

| Компонент | Параметры по умолчанию |
| :--- | :--- |
| **I2C (SDA/SCL)** | 4 / 5 |
| **PCF8574 (Входы)** | 0x22, 0x23 |
| **PCF8574 (Реле)** | 0x24, 0x25 |
| **RS485 (RX/TX)** | 16 / 13 |
| **Ethernet (MDC/MDIO)** | 23 / 18 |
| **Сеть AP по умолчанию** | SSID: `PIE_Controller`, Pass: `12345678` |
| **Логин/Пароль веб-интерфейса** | admin / admin |

## 🚀 Начало работы (Сборка и прошивка)

1. **Подготовка Arduino IDE:**
   * Установите поддержку плат **ESP32** (Board Manager).
   * Выберите плату: **ESP32 Dev Module** (или аналогичную).
   * **ВАЖНО:** В меню `Tools` → `Partition Scheme` выберите **"Huge APP (3MB No OTA/1MB SPIFFS)"**. Это необходимо, так как веб-интерфейс встроен прямо в код и занимает много места.
2. **Библиотеки:**
   Убедитесь, что в менеджере библиотек установлены следующие зависимости:
   * `ESPAsyncWebServer` (и `AsyncTCP`)
   * `ArduinoJson` (версия 7.x)
   * `ModbusMaster` (от Doc Walker)
   * `Preferences` (встроенная в ESP32)
3. **Прошивка:**
   Откройте файл `v10.ino`, скомпилируйте и загрузите проект на плату.

## 🖥️ Использование

После включения устройство доступно двумя способами:

### 1. Подключение по кабелю Ethernet
* Подключите контроллер к роутеру кабелем витая пара.
* По умолчанию устройство ожидает статический IP-адрес: **`192.168.1.100`** (если сеть не настроена). 
* Вы можете изменить этот адрес в веб-интерфейсе во вкладке **«Сеть»**.

### 2. Подключение по Wi-Fi (Точка доступа)
* Найдите в списке Wi-Fi сетей точку доступа **`PIE_Controller`**.
* Введите пароль: **`12345678`**.
* Перейдите в браузере по адресу: **`http://192.168.4.1`**.

### 🔐 Вход в систему
При первом входе введите:
* **Логин:** `admin`
* **Пароль:** `admin`
*(Рекомендуется сразу сменить пароль во вкладке "Безопасность")*.

## 🌐 Основные API эндпоинты
Прошивка предоставляет REST API для интеграции с системами умного дома (Home Assistant и др.):
* `GET /api/data` — получение телеметрии (температура, влажность, состояния реле и входов, IP-адреса).
* `GET /api/relay?ch={0-15}&state={0|1}` — управление реле (0 = выкл, 1 = вкл).
* `GET /api/net` — получение текущих сетевых настроек.
* `POST /api/net/save` — сохранение сетевых настроек (ip, mask, gw, dns).
* `POST /api/auth/save` — смена логина и пароля веб-интерфейса.
* `POST /api/wifi/save` — смена SSID и пароля точки доступа (с последующей перезагрузкой).

## 📂 Структура проекта
* `v10.ino` — главный файл (setup и loop).
* `config.h` — все пины, адреса и константы.
* `web_server.cpp` / `web_ui.h` — логика веб-сервера и встроенный HTML/CSS/JS интерфейс.
* `ethernet_link.cpp` — настройка Ethernet (LAN8720).
* `auth.cpp` — работа с логинами и паролями.
* `sensors.cpp` — опрос датчиков по Modbus RS485.
* `relays.cpp` / `inputs.cpp` — работа с PCF8574.
* `net_config.cpp` / `storage.cpp` — сохранение настроек в память ESP32.
